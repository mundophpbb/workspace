# Internationalization audit — Workspace IDE 1.58.6

This review normalizes the standalone migration inventory, diagnostic text, technical comments, the GitHub repository placeholder, project documentation, and the main README to English. Radar report-export interface labels use phpBB language keys.

English and Brazilian Portuguese language packs are retained. Portuguese text deliberately used by bilingual generators (`documentation_builder.php`, `release_notes_builder.php`, and other localization code) is intentional and must not be converted to English.

Historical release documentation was rewritten in English, and the migration inventory describes v100–v122. Full live phpBB testing, official EPV validation and cross-database upgrade testing are **not** implied by a successful static check.
